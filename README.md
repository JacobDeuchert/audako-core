Unofficial class library including core models, services and utils for audako side projects.

Published to the audako Gitea registry. Map the scope in `.npmrc`, then install:

```
@audako:registry=https://git.dev.audako.net/api/packages/audako/npm/
```

```
npm i @audako/core
```

Upgrading from 1.x: see [docs/migration-2.0.md](docs/migration-2.0.md).
